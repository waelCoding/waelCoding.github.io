# Wael Al-Haj — Software Engineer Portfolio

A modern, professional **Online CV + Developer Portfolio** website built with
**HTML5, CSS3, and Vanilla JavaScript** — no frameworks, no build step, no
dependencies. Ready to deploy on GitHub Pages.

---

## 📌 About

This is the personal portfolio of **Wael Al-Haj**, a Software Engineer
specializing in **ERP systems, APIs, Web development, Flutter applications,
and SQL databases**.

Target audience: Software Engineering Recruiters, HR Managers, Tech Companies,
Clients, and Software Developers — focused on opportunities in
**Saudi Arabia / GCC / Middle East / International**.

---

## 🚀 Features

- Modern, minimal, developer-focused design
- **Dark theme by default** with Light mode toggle
- Fully responsive (Desktop / Laptop / Tablet / Mobile)
- Mobile hamburger navigation
- Smooth scrolling & scroll spy
- Dynamic footer year
- Back-to-top button
- Subtle reveal-on-scroll animations
- SEO-friendly metadata (Open Graph + Twitter cards)
- Accessible (semantic HTML, ARIA labels, keyboard friendly)
